# Blog Platform

A markdown-powered blog platform built with React and React Router.

## Features

- Create, edit, and delete blog posts
- Markdown editor with live split-pane preview
- Tag system with add/remove and filter by tag
- Search posts by title or content
- Post list with excerpts
- Individual post view with full markdown rendering
- Reading time estimate
- Data persisted to localStorage
- Dark theme with rose accent

## Routes

- `/` — Post list
- `/post/:id` — View post
- `/new` — Create post
- `/edit/:id` — Edit post

## Tech Stack

- React (Vite)
- React Router DOM
- Marked (markdown rendering)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
